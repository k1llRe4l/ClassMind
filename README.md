# ClassMindRAG

Локальное Flask-приложение для семантического поиска по учебным материалам и заметкам по испанской грамматике.

ClassMindRAG использует ChromaDB для хранения и поиска векторных представлений материалов. Найденные материалы отображаются на странице результатов вместе с соответствующими изображениями в интерактивной карусели.

## Возможности

- семантический поиск по испанским грамматическим темам;
- локальное хранение данных в ChromaDB;
- автоматическое добавление демонстрационных материалов при пустой базе;
- выдача до трёх наиболее релевантных результатов;
- отображение заголовка и связанного изображения каждого материала;
- поддержка изображений `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` и `.svg`;
- адаптивная карусель со стрелками, индикаторами и поддержкой свайпа;
- обработка отсутствующих изображений без ошибки страницы.

## Технологии

- Python 3
- Flask 3.1
- ChromaDB 0.5
- Jinja2
- HTML, CSS и vanilla JavaScript
- локальная функция эмбеддингов ChromaDB

## Структура проекта

```text
ClassMindRAG/
├── app.py                  # Flask-приложение и логика поиска
├── requirements.txt        # Зависимости проекта
├── my_grammar_db/          # Локальное хранилище ChromaDB
├── static/
│   ├── style.css           # Стили страниц
│   └── images/             # Изображения учебных материалов
└── templates/
    ├── index.html          # Главная страница с формой поиска
    ├── response.html       # Страница результатов и карусели
```

## Установка

Откройте терминал в каталоге проекта и создайте виртуальное окружение:

```powershell
py -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

Запустите Flask:

```powershell
python -m flask --app app.py run
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5000/
```

На главной странице введите запрос, например:

- `неправильные глаголы`;
- `presente de indicativo`;
- `verbos reflexivos`;
- `прошедшее время`.

Кнопка «Найти» открывает страницу `/response`, где отображаются найденные материалы.

## Изображения материалов

Каждый документ в коллекции имеет уникальный идентификатор, например `doc_img_01`. Приложение ищет изображение с таким же именем в каталоге `static/images/`, независимо от поддерживаемого расширения файла.

Пример:

```text
ID документа: doc_img_01
Изображение: static/images/doc_img_01.jpg
```

URL изображения формируется через Flask `url_for('static', ...)`. Абсолютные пути файловой системы в браузер не передаются.

## ChromaDB

Локальная база сохраняется в каталоге:

```text
./my_grammar_db
```

Используется коллекция:

```text
grammar_images
```

При первом запуске, если коллекция пуста, приложение добавляет демонстрационные записи для материалов по неправильным испанским глаголам.
